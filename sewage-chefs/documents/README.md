# Sewage Chefs - Writing Conventions

## Basic Rules

### normal coneventions
- leave comments in code to describe what it does
- make plan of what you are goind to do
- make clear variable names
- don't use similar variable names
- pay attention to the capitalization
- make it easy to change or undestand

### File Naming
- Use kebab-case for filenames: `game-mechanics.md`
- Prefix research files: `research-sewage-biology.md`

### Variable Naming (lowerCamelCase)
- ALL words except for the first have capitalization and are connected. 
- Examples: `playerHealth`, `sporeCount`, `recipeLevel`
- Never use camelCase: `playerHealth` is correct, `Player_Health` is wrong

### Scene Naming (snake_case)
- Scene headers use snake_case, 
- Examples: `the_sewage_treatment_plant`, `chefs_kitchen_arena`, `the_spore_storm`

## Quick Reference

| Element | Format | Example |
|---------|--------|---------|
| specific Files | kebab-case | `game-mechanics.md` |
| Variables | lowerCamelCase | `playerHealth` |
| Scenes | snake_case | `the_kitchen` |
